#     PIP_CONSTRAINT the def builds).

#     nese-training are editable installs done in %post, not listed here.
#   - mpi4py is NOT here either: PyPI's manylinux wheels bundle their own MPICH,
#     so it gets its own `--no-binary` line in %post, built against the
