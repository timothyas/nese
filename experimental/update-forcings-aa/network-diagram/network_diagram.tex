\figurepage{encoder_figure}{%
  \textbf{Encoder.}\;
  \texttt{GraphTransformerForwardMapper} maps the data-space input onto the latent mesh.
  The input $\inputvec$ is assembled per data node.
  The field encoder passes each field's observations through one MLP shared across
  missions and averages over the missions that observed the node, at each of the $\NT$
  observed steps; counts act only as the mask.
  Dynamic forcings are also given at the $\NTf$ target step, static forcings once.
  Shapes are for one batch element and ensemble member.
  The source nodes are returned unchanged, so all three residual paths act on the latent
  stream.}

\figurepage{processor_figure}{%
  \textbf{Processor.}\;
  \texttt{RadiusTransformerProcessor}: $\NL$ pre-norm transformer blocks over the latent
  nodes, each attending only along the $\NPE$ latent-to-latent edges plus itself ---
  a disc of about \valproccutoffkm\,km, \valprocdegmean\ neighbours on average.
  The \texttt{latent\_skip} add belongs to the model rather than to the processor.}

\figurepage{decoder_figure}{%
  \textbf{Decoder.}\;
  \texttt{GraphTransformerBackwardMapper}, the encoder's block with the two spaces
  exchanged.  It has no source embedding, and its destination input is the raw
  $\inputvec$, re-embedded by its own Linear.
  \texttt{node\_data\_extractor} emits the $\Nnet$ network outputs
  (\valnetnamesplain); the physics block, defined per diagnostic, computes the other
  $\Nphys$ (\valphysnamesplain) from them and from static fields, with gradients.
  All are diagnostic ($\idxprog = \varnothing$), so the prognostic residual add is empty.}
